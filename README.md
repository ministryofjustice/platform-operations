## About this repository

This is the Ministry of Justice (MoJ) [Platform Operations team](https://github.com/orgs/ministryofjustice/teams/platform-operations)'s repository for core work and public facing documentation.

The Platform Operations team is responsible for:
- Hosting and managing the Infrastructure for Digital Studio Operations (DSO) projects
- Hosting and managing the Infrastructure for Probations projects
- Managing the Azure HMPPS Tenant, including nomsdigitech Entra ID (the location for AppInsights)

We work closely with DBAs, Application Support Teams, HMPPS Devs, NART and the Modernisation Platform Team.
